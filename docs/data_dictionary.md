# CreditWise - Alternative Credit Data Dictionary

This dataset is fully synthetic and does not contain real customer information.

## Columns

| Column | Type | Description |
|---|---:|---|
| customer_id | string | Synthetic unique identifier for the customer. |
| customer_name | string | Synthetic name generated by Faker. Not used as a model feature. |
| age | int | Customer age. |
| employment_type | string | Employment type: salaried, self_employed, contract, gig, retired, unemployed. |
| monthly_income | float | Synthetic monthly income in arbitrary units. |
| months_at_current_address | int | Number of months the customer has stayed at the current address. |
| number_of_dependents | int | Number of financial dependents. |
| has_rent_history | int | Whether the customer has rent payment history: 1 = yes, 0 = no. |
| rent_payment_on_time_rate | float | Ratio of on-time rent payments from 0 to 1. Missing if no rent history. |
| utility_payment_on_time_rate | float | Ratio of on-time utility payments from 0 to 1. |
| telecom_payment_on_time_rate | float | Ratio of on-time telecom payments from 0 to 1. |
| monthly_avg_telco_charge | float | Average monthly telecom charge amount. |
| ecommerce_activity_score | float | Synthetic e-commerce activity score from 0 to 100. |
| digital_wallet_usage_score | float | Synthetic digital wallet usage score from 0 to 100. |
| savings_behavior_score | float | Synthetic savings behavior score from 0 to 100. |
| is_default_12m | int | Target variable: whether the customer defaulted within 12 months. |

## Important Notes

- `customer_name` is synthetic and must not be used for model training.
- `is_default_12m` is the supervised learning target.
- Missing `rent_payment_on_time_rate` is meaningful and should be handled with `has_rent_history`.
- This dataset is designed for prototype development, not production credit decisions.
